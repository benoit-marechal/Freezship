# Freezship

Jeu spatial conservé dans sa version de 2007, partagé comme archive pédagogique.

## Commandes

- Déplacer le vaisseau avec les touches fléchées.
- Appuyer sur M pour passer en mode shoot ’em up.
- Appuyer sur B pour larguer une bombe dans ce mode.

L’exécutable Windows historique `mygame.exe` est conservé dans le dossier [exe](exe/).
